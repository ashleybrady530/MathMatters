Math Structure Matters

Mathematical content can look correct on a screen while containing different information underneath. These examples show how authoring choices in an equation editor affect mathematical structure and how MathJax can use that structure.

Checking MathJax…

About this demonstration: This page uses MathJax 4. The CourseArc examples use MathML generated by the WIRIS equation editor. No custom spoken descriptions have been added to the equations.

1. Math Within a Sentence

Mathematical notation can remain within a sentence when that placement reads naturally. Creating math in an equation editor does not mean it needs to appear on its own line.

Plot the point ( 3 , − 2 ) on the coordinate plane. Then use d = r × t to calculate the distance traveled.

The coordinate and equation are structured math, but they still fit naturally within the surrounding sentence.

View MathML Structure 
<!-- Coordinate -->
<math xmlns="http://www.w3.org/1998/Math/MathML">
  <mo>(</mo>
  <mn>3</mn>
  <mo>,</mo>
  <mo>−</mo>
  <mn>2</mn>
  <mo>)</mo>
</math>

<!-- Exact CourseArc/WIRIS output for d = r × t -->
<math xmlns="http://www.w3.org/1998/Math/MathML">
  <mi>d</mi>
  <mo>=</mo>
  <mi>r</mi>
  <mo>&#215;</mo>
  <mi>t</mi>
</math>

2. Text Is Not a Variable

Simply typing letters in an equation editor identifies them as mathematical content. When letters form a word, label, abbreviation, or unit, use the editor's Text function.

Typed as ordinary math

60   m p h

This is the structure CourseArc/WIRIS generates when mph is typed as ordinary mathematical letters.

Using Text for the unit

60   mph

This is the structure CourseArc/WIRIS generates when mph is entered using the Text function.

In the second example, mph is text representing the unit abbreviation for miles per hour rather than three mathematical identifiers.

View MathML Structure 
<!-- CourseArc/WIRIS: typed as ordinary math -->
<math xmlns="http://www.w3.org/1998/Math/MathML">
  <mn>60</mn>
  <mo>&#160;</mo>
  <mi>m</mi>
  <mi>p</mi>
  <mi>h</mi>
</math>

<!-- CourseArc/WIRIS: mph entered using Text -->
<math xmlns="http://www.w3.org/1998/Math/MathML">
  <mn>60</mn>
  <mo>&#160;</mo>
  <mtext>mph</mtext>
</math>

3. Structure Determines Meaning

Equation-editor templates create relationships between parts of an expression. These examples show why it matters where the exponent is attached.

The whole expression is squared

( x + 2 ) 2

The entire parenthetical expression is grouped as the base of the exponent.

WIRIS normalizes the structure

( x + 2 ) 2

A different editing path in CourseArc produced the same saved MathML structure as the intended version.

The exponent is attached to 2)

( x + 2 ) 2

This can look deceptively close, but the exponent is attached to the grouped content 2), not to the entire expression.

When using superscripts, subscripts, fractions, radicals, or similar templates, make sure the intended content is in the correct part of the equation editor.

View MathML Structure 
<!-- Whole expression is the base -->
<math xmlns="http://www.w3.org/1998/Math/MathML">
  <msup>
    <mrow>
      <mo>(</mo>
      <mi>x</mi>
      <mo>+</mo>
      <mn>2</mn>
      <mo>)</mo>
    </mrow>
    <mn>2</mn>
  </msup>
</math>

<!-- CourseArc/WIRIS alternate editing path:
     saved as the same structure above. -->

<!-- Exponent attached to the grouped content 2) -->
<math xmlns="http://www.w3.org/1998/Math/MathML">
  <mo>(</mo>
  <mi>x</mi>
  <mo>+</mo>
  <msup>
    <mrow>
      <mn>2</mn>
      <mo>)</mo>
    </mrow>
    <mn>2</mn>
  </msup>
</math>

4. Explore the Quadratic Formula

When mathematical relationships are structured correctly, MathJax can use that structure for speech and expression exploration.

Quadratic Formula: x = − b ± b 2 − 4 a c 2 a

Quadratic Formula is identified as text, while the formula preserves nested mathematical relationships including a fraction, numerator, denominator, radical, exponent, operators, and variables.

Try the MathJax accessibility tools

  1. Right-click or control-click the formula.
  2. Open the MathJax accessibility options.
  3. Explore the speech and expression-exploration features.
  4. Move through individual parts of the formula and notice how the nested relationships are identified.
View MathML Structure 
<math xmlns="http://www.w3.org/1998/Math/MathML" display="block">
  <mtext>Quadratic Formula:</mtext>
  <mi>x</mi>
  <mo>=</mo>
  <mfrac>
    <mrow>
      <mo>−</mo>
      <mi>b</mi>
      <mo>±</mo>
      <msqrt>
        <mrow>
          <msup>
            <mi>b</mi>
            <mn>2</mn>
          </msup>
          <mo>−</mo>
          <mn>4</mn>
          <mi>a</mi>
          <mi>c</mi>
        </mrow>
      </msqrt>
    </mrow>
    <mrow>
      <mn>2</mn>
      <mi>a</mi>
    </mrow>
  </mfrac>
</math>
MathML 101

You do not need to write MathML to create structured equations. Equation editors such as WIRIS generate this structure based on how you use the editor. These are some of the elements used in the examples above.

<mi>
A mathematical identifier, such as a variable.
<mn>
A number.
<mo>
A mathematical operator or delimiter.
<mtext>
Text within math, such as a word, label, abbreviation, or unit.
<mrow>
Groups related parts of an expression. It does not add visible notation itself; it identifies which pieces belong together.
<msup>
Identifies a base and its superscript.
<msub>
Identifies a base and its subscript.
<msubsup>
Identifies a base with both a subscript and a superscript.
<mfrac>
Identifies the numerator and denominator of a fraction.
<msqrt>
Identifies the expression contained within a square root.
<mroot>
Identifies a radical with an explicit index, such as a cube root.

The important part: authors normally create these relationships by using the equation editor's fields, templates, symbols, and Text function correctly. Writing MathML tags yourself is not required.

This demonstration shows MathJax 4 working with structured MathML. Course platforms may use different versions, configurations, or equation editors.
